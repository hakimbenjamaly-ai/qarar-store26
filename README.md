# قرار – منصة التجارة والاستيراد والتوزيع في ليبيا

متجر إلكتروني عربي (RTL) مع لوحة إدارة، مبني ليعمل بنموذج مختلط: منتجات متوفرة محلياً ومنتجات تُستورد عند الطلب، مع فصل كامل بين طلب العميل وأمر الشراء من المورد والشحنة الدولية وطلب التوصيل المحلي (النورس).

- التقنيات: Next.js 15 · TypeScript · PostgreSQL · Prisma · Tailwind CSS
- وثيقة التحليل (قاعدة البيانات، دورة الطلب، طريقة الربط): انظر رابط الوثيقة في طلب الدمج.
- تعليمات النشر على خادم: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)
- دليل استخدام لوحة الإدارة: [docs/ADMIN-GUIDE.md](docs/ADMIN-GUIDE.md)

## ما يشمله الإصدار الحالي (المراحل ١ إلى ٣)

**المتجر:** الصفحة الرئيسية (مختارات، الأكثر طلباً من المبيعات الفعلية، العروض، وصل حديثاً) · الأقسام والأقسام الفرعية · البحث مع فلاتر السعر والتوفر والترتيب · صفحة المنتج (صور متعددة، خيارات المقاس واللون، المواصفات، بلد المنشأ، مدة التوريد، التقييمات) · السلة · إتمام الطلب (المدينة ورسوم التوصيل، طرق الدفع المفعّلة) · متابعة الطلب برقم الطلب + الهاتف · تقييم المنتج بعد استلامه · اتصل بنا · السياسات · الأسئلة الشائعة.

**لوحة الإدارة:** لوحة المؤشرات مع فلاتر التاريخ والقسم · المنتجات مع حاسبة السعر والتكاليف الداخلية · الأقسام · الموردون (بيانات أساسية) · الطلبات وتغيير الحالة على مستوى الطلب أو البند · الدفعات والعربون والمتبقي · طباعة الفاتورة · العملاء · التقييمات · رسائل العملاء · الإشعارات الداخلية · الإعدادات (الاسم، الشعار، لون العلامة، السياسات، طرق الدفع، المدن والمناطق ورسوم التوصيل، أسعار الصرف، العربون) · المستخدمون والأدوار التسعة مع صلاحيات قابلة للتعديل · سجل العمليات.

**المشتريات والشحن (المرحلة ٢):** صفحة المورد وربط المنتجات برابط وسعر المورد وتاريخ آخر تحقق · قائمة «بانتظار الشراء» وإنشاء أوامر الشراء منها · أوامر شراء للمخزون · المرفقات (فواتير، بوالص، إيصالات) · شركات الشحن وروابط التتبع · الشحنات الدولية مع تقسيم الكميات وتوزيع تكلفة الشحن والجمارك · تحديث حالات بنود العملاء والمخزون تلقائياً · التكلفة الفعلية والربح الفعلي في الطلب ولوحة المؤشرات. كل ذلك يدوي، بلا ادعاء ربط API مع الموردين أو شركات الشحن.

**التوزيع المحلي (المرحلة ٣):** قائمة الطلبات الجاهزة وتجهيز الطرود · ملصقات الطرود · دفعات التسليم للنورس مع كشف للتوقيع · ملف Excel (CSV) للتصدير والاستيراد · حالات التوصيل والتعذر والمرتجعات وانعكاسها على الطلب والمخزون · بوابة موظف النورس المقيّدة بشركته · التسويات المالية وتحويل المبالغ المحصلة إلى دفعات على الطلبات · مؤشرات أجور التوصيل والمبالغ غير المسوّاة. بدون ادعاء ربط API مع النورس.

## التشغيل محلياً

```bash
cp .env.example .env          # عدّل DATABASE_URL
npm install
npx prisma migrate deploy     # إنشاء الجداول
npm run db:seed               # الأدوار، طرق الدفع، هيكل الأقسام، أسماء المدن (غير مفعّلة)
npm run create-admin -- --email you@example.com --name "اسمك" --password "كلمة-مرور-قوية"
npm run dev                   # http://localhost:3000  والإدارة على /admin
```

البذور لا تضيف منتجات أو أسعاراً أو طلبات وهمية. بعد الدخول: أضف أسعار الصرف، فعّل المدن مع رسوم التوصيل، ثم أضف المنتجات.

## الاختبارات

```bash
npm test                      # اختبارات الوحدات (التسعير، الحالات، أرقام الهواتف)
npm run typecheck && npm run lint
# اختبار المسار الكامل في المتصفح (يُنشئ بيانات، فشغّله على قاعدة اختبار):
BASE_URL=http://localhost:3000 ADMIN_EMAIL=... ADMIN_PASSWORD=... npm run test:e2e             # المراحل ١ و٢ و٣ (يتطلب DATABASE_URL للتحقق من المخزون)
```

## هيكل المشروع

```
prisma/schema.prisma        هيكل قاعدة البيانات الكامل
prisma/seed.ts              البيانات الأساسية
src/lib/                    المنطق: الطلبات، الحالات، التسعير، الصلاحيات، الإعدادات
src/app/(store)/            واجهة المتجر
src/app/admin/              لوحة الإدارة
tests/                      الاختبارات
```
